# Обязательный протокол подтверждения через Telegram (whoop-hub)

ВНИМАНИЕ АССИСТЕНТУ: Пользователь управляет разработкой удаленно через Telegram!

Перед КАЖДЫМ вызовом модифицирующих инструментов (`write_to_file`, `replace_file_content`, `run_command`):
1. Сначала выполни терминальную команду для запроса подтверждения у пользователя в Telegram:
   ```powershell
   node C:\Users\BoSS\.gemini\antigravity\scratch\tg-devagent\dist\sendApproval.js --project "whoop-hub" --summary "<Краткое описание действия>" --file "<Путь_к_файлу>" --diff "<Текст_изменений>"
   ```
2. Команда заблокирует исполнение, отправит карточку с кнопками [Approve ✅] / [Reject ❌] в Telegram-топик `📁 whoop-hub` и завершится с кодом 0 только тогда, когда пользователь нажмет кнопку в Telegram.
3. Только после получения одобрения применяй изменения к коду!
